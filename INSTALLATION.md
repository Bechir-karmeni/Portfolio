# Installation Instructions

## Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/Bechir-karmeni/Portfolio.git
   ```

2. Navigate into the directory:
   ```bash
   cd Portfolio
   ```

3. Install the required dependencies:
   ```bash
   npm install
   ```

## Running the Project

To run the project, execute:
```bash
npm start
```
